### 13:30–14:30：Kafka 基础

观看 [尚硅谷 Kafka 3.x 教程](https://www.bilibili.com/video/BV1vr4y1677k) P2-P5，并阅读 [Kafka Introduction](https://kafka.apache.org/intro/)。

建立概念对应：

```
Producer：发送事件的 Go 服务
Topic：事件类别，例如 post-liked
Partition：Topic 的并行分片
Broker：Kafka 服务节点
Consumer：处理通知或统计的服务
Consumer Group：共同消费任务的一组实例
```

重点理解：

- Kafka 存储的是事件，不是最终业务状态
- Producer 和 Consumer 不需要同步等待
- 同一 Consumer Group 内，一条消息通常只由一个实例处理
- 消费者必须考虑重复消息，因此处理逻辑要具备幂等性

### 14:30–15:30：Kafka 实践，可选

按照当前 [Kafka Quickstart](https://kafka.apache.org/quickstart/) 或官方 Docker 方案启动 Kafka，避免 ZooKeeper 旧教程。

完成：

1. 创建 `post-liked` Topic。
2. Producer 发送一条 JSON 消息。
3. Consumer 接收消息。
4. 停止 Consumer 后继续生产消息。
5. 重启 Consumer，观察消息是否继续被处理。

示例消息：

```
{
  "event_id": "evt_001",
  "post_id": 1001,
  "user_id": 2001,
  "created_at": "2026-08-29T15:00:00+08:00"
}
```
