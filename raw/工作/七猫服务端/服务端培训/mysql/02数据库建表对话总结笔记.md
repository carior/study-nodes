### 一、创建书籍表和章节表

#### 1. 书籍表（books）完整 DDL

```sql
CREATE TABLE books (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '书籍ID，主键',
    title VARCHAR(255) NOT NULL COMMENT '书名',
    author VARCHAR(100) NOT NULL COMMENT '作者',
    isbn VARCHAR(20) UNIQUE COMMENT 'ISBN号，唯一',
    publisher VARCHAR(100) COMMENT '出版社',
    publish_date DATE COMMENT '出版日期',
    category VARCHAR(50) COMMENT '分类/体裁',
    total_chapters INT DEFAULT 0 COMMENT '总章节数（冗余字段，便于展示）',
    status TINYINT DEFAULT 1 COMMENT '状态：1-连载中，2-已完结，3-下架',
    cover_image VARCHAR(500) COMMENT '封面图URL',
    description TEXT COMMENT '书籍简介',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_author (author),
    INDEX idx_category (category),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='书籍表';
```

#### 2. 章节表（chapters）完整 DDL

```sql
CREATE TABLE chapters (
    id INT PRIMARY KEY AUTO_INCREMENT COMMENT '章节ID，主键',
    book_id INT NOT NULL COMMENT '所属书籍ID，外键',
    chapter_number INT NOT NULL COMMENT '章节序号（第几章）',
    title VARCHAR(255) NOT NULL COMMENT '章节标题',
    subtitle VARCHAR(255) COMMENT '副标题',
    content LONGTEXT COMMENT '章节正文内容',
    word_count INT DEFAULT 0 COMMENT '字数统计',
    is_free TINYINT DEFAULT 0 COMMENT '是否免费：0-付费，1-免费',
    status TINYINT DEFAULT 1 COMMENT '状态：1-已发布，2-草稿，3-已下架',
    sort_order INT DEFAULT 0 COMMENT '排序权重',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    CONSTRAINT fk_chapter_book FOREIGN KEY (book_id) REFERENCES books(id) ON DELETE CASCADE ON UPDATE CASCADE,
    UNIQUE KEY uk_book_chapter (book_id, chapter_number),
    INDEX idx_book_id (book_id),
    INDEX idx_status (status),
    INDEX idx_is_free (is_free)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='章节表';
```

### 二、关键知识点

#### 1. 数据类型

| 类型 | 字节数 | 范围 | 用途 |
|---|---|---|---|
| `TINYINT` | 1 | -128~127（有符号）/ 0~255（无符号）| 状态码、开关、小数字 |
| `INT` | 4 | -21亿~21亿 | 常规ID、数量 |
| `VARCHAR(n)` | 可变 | 最多 n 个字符 | 标题、作者、URL |
| `TEXT` | 可变 | 最多 65535 字符 | 文章内容、简介 |
| `DATETIME` | 8 | 1000~9999年 | 时间记录 |
| `DATE` | 3 | 1000~9999年 | 日期（无时间）|

> **读音**：TINYINT = /ˈtaɪni ɪnt/（泰尼·因特）

---

#### 2. 索引（INDEX）

```sql
INDEX idx_author (author)  -- 普通索引，加快 WHERE author = 'xxx' 的查询
```

| 索引类型 | 关键字 | 特点 |
|---|---|---|
| 普通索引 | `INDEX` | 允许重复值，只提速查询 |
| 唯一索引 | `UNIQUE INDEX` | 不允许重复值，提速查询 + 保证唯一性（如 isbn） |
| 主键 | `PRIMARY KEY` | 唯一 + 非空，每表只能有一个，同时也是聚簇索引 |

**命名规范**：
- `idx_` 前缀 = 普通索引（如 `idx_author`）
- `uk_` 前缀 = 唯一索引（如 `uk_isbn`）
- `fk_` 前缀 = 外键（如 `fk_chapter_book`）

#### 3. 约束（Constraint）

##### 外键约束

```sql
CONSTRAINT fk_chapter_book 
FOREIGN KEY (book_id) 
REFERENCES books(id) 
ON DELETE CASCADE 
ON UPDATE CASCADE
```

| 关键词 | 含义 |
|---|---|
| `CONSTRAINT fk_chapter_book` | | `CONSTRAINT fk_chapter_book` | 书被删除 → 章节自动全删 |
 |
| `FOREIGN KEY (book_id)` | 当前表的 book_id 字段是外键 |
| `REFERENCES books(id)` | 它引用的是 books 表的 id 字段 |
| `ON DELETE CASCADE` | 书被删除 → 章节自动全删 |
| `ON UPDATE CASCADE` | 书的 ID 变了 → 章节的 book_id 自动跟着变 |


> **作用**：保证数据一致性，书没了，章节跟着没。

##### 实际例子
```sql
-- 删除 id=1 的书籍
DELETE FROM books WHERE id = 1;

-- 由于 ON DELETE CASCADE，chapters 表中所有 book_id=1 的章节会被自动删除
-- 不用你手动去删！
```

##### 联合唯一约束

```sql
UNIQUE KEY uk_book_chapter (book_id, chapter_number)
```

> 同一本书里不能有两个“第1章”——`(book_id, chapter_number)` 组合全局唯一。

---

#### 4. 表属性（ENGINE / CHARSET / COMMENT）

```sql
ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='书籍表';
```

| 属性 | 含义 | 是否必写 |
|---|---|---|
| `ENGINE=InnoDB` | 存储引擎（支持事务、外键、行级锁）| 建议写 |
| `DEFAULT CHARSET=utf8mb4` | 字符集（支持 Emoji，防乱码）| 建议写 |
| `COMMENT='书籍表'` | 表注释（说明用途，方便协作）| 建议写 |

> `DEFAULT` 关键字可省略，但建议保留以明确含义。

---

#### 5. 字段属性

| 关键字 | 含义 |
|---|---|
| `NOT NULL` | 该字段不能为空 |
| `DEFAULT 值` | 不填时自动填入默认值 |
| `AUTO_INCREMENT` | 自增（通常用于主键 ID）|
| `ON UPDATE CURRENT_TIMESTAMP` | 每次更新时自动刷新为当前时间 |

> **注意**：`created_at` 只应写 `DEFAULT CURRENT_TIMESTAMP`，**不要**加 `ON UPDATE`，否则创建时间会被误更新。

### 三、可视化工具操作要点

1. 右键表 → **编辑表结构** 进入设计界面
2. 添加字段：点击 **+ 新增字段**，填写字段名、类型、长度、注释
3. 设置唯一约束：
   - 方式一：字段列表中直接勾选 **“唯一”** 复选框
   - 方式二：切换到 **索引** 标签，新增索引，类型选 `UNIQUE`
4. 修改后记得 **保存（Ctrl+S）**
5. 左侧目录树右键 → **刷新（F5）** 查看最新结构

### 四、建表最佳实践

- ✅ 每张表都要有 `id` 主键 + `created_at` / `updated_at` 时间戳
- ✅ 用 `TINYINT` 存状态/枚举值，省空间
- ✅ 经常查询的字段建索引（`WHERE`、`ORDER BY`、`GROUP BY`）
- ✅ 唯一性要求的字段加 `UNIQUE` 约束（如 ISBN）
- ✅ 外键关系用 `FOREIGN KEY` 保证数据一致性
- ✅ 字符集统一用 `utf8mb4`（支持 Emoji）
- ✅ 表和字段都要加 `COMMENT` 注释，方便团队协作
- ❌ 不要物理删除数据（用 `status` 或 `deleted_at` 做软删除）
- ❌ 内容很大的字段（如长篇小说正文）建议存对象存储（OSS），表中只存 URL
