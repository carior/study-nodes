# Go 基础语法

## 1. 程序基本结构

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
```

- `package main` 声明可执行程序包。
- `import` 用于导入其他包。
- `main()` 是程序入口。
- Go 使用 `{}` 表示代码块，通常不写分号。

## 2. 变量与常量

### 声明变量

```go
var name string = "Tom"
var age int = 18
var city = "Shanghai" // 自动推断类型
var x, y int = 10, 20
```

函数内部可以使用短变量声明：

```go
count := 100
message := "hello"
```

`:=` 只能在函数内部使用。

### 零值

变量即使没有主动赋值，也有默认值：

```go
var number int          // 0
var price float64       // 0
var enabled bool        // false
var text string         // ""
var users []string      // nil
var data map[string]int // nil
```

### 常量

```go
const Pi = 3.14159
const MaxRetry int = 3

const (
	StatusPending = iota // 0
	StatusRunning        // 1
	StatusDone           // 2
)
```

## 3. 基本数据类型

```go
var a int = 10
var b int64 = 100
var c uint = 20

var price32 float32 = 9.9
var price64 float64 = 99.99

var isReady bool = true
var text string = "你好，Go"
```

常见整数类型包括 `int`、`int8`、`int16`、`int32`、`int64` 以及对应的无符号类型。

### byte、rune 与字符串

```go
text := "你好，Go"
firstByte := text[0] // byte，即 uint8

for _, char := range text {
	fmt.Printf("%c\n", char) // char 是 rune，即 int32
}
```

- `byte` 通常表示一个字节。
- `rune` 通常表示一个 Unicode 字符。
- `len(text)` 返回字节数，不一定是字符数。

### 类型转换

Go 一般不会自动转换不同数值类型：

```go
age := 18
price := float64(age)
```

## 4. 函数

### 普通函数与多返回值

```go
func add(a, b int) int {
	return a + b
}

func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, fmt.Errorf("除数不能为 0")
	}
	return a / b, nil
}
```

调用函数并处理错误：

```go
result, err := divide(10, 2)
if err != nil {
	fmt.Println("计算失败：", err)
	return
}
fmt.Println(result)
```

### 可变参数

```go
func sum(numbers ...int) int {
	total := 0
	for _, number := range numbers {
		total += number
	}
	return total
}
```

### 匿名函数

```go
multiply := func(a, b int) int {
	return a * b
}
```

## 5. 结构体

结构体用于组合多个字段：

```go
type User struct {
	ID   int
	Name string
	Age  int
}

user := User{ID: 1, Name: "Tom", Age: 18}
```

为结构体定义方法：

```go
func (u User) Introduce() string {
	return fmt.Sprintf("我叫%s，今年%d岁", u.Name, u.Age)
}
```

需要修改结构体时，通常使用指针接收者：

```go
func (u *User) Birthday() {
	u.Age++
}
```

## 6. 数组与切片

### 数组

数组长度是类型的一部分：

```go
var numbers [3]int
names := [3]string{"Tom", "Jerry", "Alice"}
scores := [...]int{90, 85, 100}
```

`[3]int` 和 `[4]int` 是不同类型。实际开发中切片使用得更多。

### 切片

```go
numbers := []int{10, 20, 30}
numbers = append(numbers, 40)

fmt.Println(len(numbers)) // 长度
fmt.Println(cap(numbers)) // 容量
```

使用 `make` 创建切片：

```go
items := make([]int, 3)
buffer := make([]int, 0, 8)
```

截取和复制：

```go
numbers := []int{10, 20, 30, 40, 50}
part := numbers[1:4] // [20 30 40]

target := make([]int, len(numbers))
copy(target, numbers)
```

切片通常共享底层数组，修改子切片可能影响原切片。

## 7. Map

Map 用于存储键值对：

```go
scores := map[string]int{
	"Tom":   90,
	"Jerry": 85,
}

scores["Alice"] = 95
delete(scores, "Tom")
```

判断键是否存在：

```go
score, exists := scores["Alice"]
if exists {
	fmt.Println(score)
}
```

遍历 Map：

```go
for name, score := range scores {
	fmt.Println(name, score)
}
```

Map 的遍历顺序不固定。未初始化的 `nil map` 可以读取，但不能写入。

## 8. 条件与循环

### if 与 switch

```go
if age >= 18 {
	fmt.Println("成年人")
} else {
	fmt.Println("未成年人")
}

switch day {
case 1:
	fmt.Println("星期一")
case 2:
	fmt.Println("星期二")
default:
	fmt.Println("其他")
}
```

Go 的 `case` 默认不会继续执行下一个分支，一般不需要 `break`。

### for 循环

Go 只有 `for` 一种循环关键字：

```go
for i := 0; i < 5; i++ {
	fmt.Println(i)
}

count := 0
for count < 5 {
	count++
}

for {
	break
}
```

遍历切片：

```go
for index, name := range names {
	fmt.Println(index, name)
}
```

使用 `continue` 跳过本轮，使用 `break` 结束循环。

## 9. 错误处理

Go 没有传统的 `try/catch`。普通错误通过 `error` 返回值显式处理：

```go
func findUser(id int) (User, error) {
	if id <= 0 {
		return User{}, fmt.Errorf("无效的用户 ID：%d", id)
	}
	return User{ID: id, Name: "Tom", Age: 18}, nil
}
```

创建、包装和判断错误：

```go
var ErrUserNotFound = errors.New("用户不存在")

if errors.Is(err, ErrUserNotFound) {
	fmt.Println("没有找到用户")
}

return fmt.Errorf("读取用户信息失败：%w", err)
```

### defer

`defer` 会在当前函数返回前执行，常用于释放资源：

```go
file, err := os.Open("data.txt")
if err != nil {
	return err
}
defer file.Close()
```

多个 `defer` 按后进先出的顺序执行。

### panic 与 recover

`panic` 表示程序遇到无法正常继续的异常情况。普通业务错误应该返回 `error`，不要滥用 `panic`。`recover` 只能在延迟函数中捕获当前 goroutine 的 `panic`。
