## 核心概念关系

```text
客户端
  |
  v
域名 / 云负载均衡
  |
  v
API 网关
  |
  v
Service / 服务注册与发现
  |
  +-> 服务实例 A
  +-> 服务实例 B
  +-> 服务实例 C
          |
          +-> Redis：缓存和高速数据访问
          +-> MySQL：持久化业务数据
          +-> Kafka：异步消息和系统解耦
```

可以用银行理解这些概念：

| 技术概念 | 银行类比 |
|---|---|
| 服务 | 一类银行业务 |
| 服务实例 | 多个办理相同业务的窗口 |
| 网关 | 银行大厅入口和接待台 |
| 负载均衡 | 取号和分流系统 |
| Kubernetes | 管理窗口开放、关闭和调度的系统 |
| 数据库 | 银行账本 |
| 数据库事务 | 一套操作全部入账或全部撤销 |
| 唯一索引 | 同一个业务流水号只能登记一次 |
| 乐观锁 | 提交前检查账本是否已被修改 |
| 悲观锁 | 先锁住账本，处理完成后再交还 |
| 分布式锁 | 某份特殊材料同时只能由一个窗口办理 |
| 请求幂等 | 同一凭证重复提交也只办理一次 |
| Kafka 去重 | 同一通知单重复送达也不能重复入账 |
